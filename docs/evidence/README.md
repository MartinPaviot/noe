# Preuves d'exécution

Captures d'écran des étapes clés d'une automatisation navigateur, exigées par
`docs/doctrine-execution.md`.

**Rien n'est commité par défaut.** Le dépôt est public, et une page de
facturation ou de permissions expose des identifiants de compte. Chaque capture
est inspectée avant d'être ajoutée explicitement au suivi ; en cas de doute, elle
reste locale et seul son constat est consigné dans le journal.
