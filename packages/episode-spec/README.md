# @noe/episode-spec

Schemas du format d'episode de Noe.

Ce package est sous **licence MIT**, volontairement distincte de l'AGPL-3.0 du reste
du depot : le format d'episode doit pouvoir etre lu, valide et reimplemente par
n'importe qui, y compris dans un produit proprietaire. C'est un format, pas un moteur.

En session 0 il est vide : le format est la feature F02.
